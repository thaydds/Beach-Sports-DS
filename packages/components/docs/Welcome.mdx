# Beach Sports DS

Design system do produto Beach Sports: tokens em DTCG compilados para CSS
custom properties e componentes React com CSS Modules.

Esta página é o ponto de entrada do Storybook. Componentes entram nas próximas
etapas, cada um com a matriz de variantes do Figma, os dois temas e os testes de
acessibilidade na mesma página.

## Tema

Claro é o padrão (`:root`). Escuro é opt-in via `data-theme="dark"` no elemento
raiz — use a toolbar **Tema** para alternar sem re-renderizar componentes.

## Base de revisão

O viewport padrão é **393×852** (mobile), conforme o contrato de layout do DS.
