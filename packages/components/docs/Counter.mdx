# Counter

Uma entrada para um inteiro, com casas visuais separadas e ações empilhadas. `digits` deriva o intervalo; `value` e `onChange` sempre representam o número completo. Sem truncamento ao trocar a quantidade de casas. Use um nome por time e `onValidityChange` para bloquear confirmação enquanto houver entrada inválida.
